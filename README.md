# 🏦 Bank Customer Segmentation Using Power BI

## 📌 Project Overview

This project focuses on analyzing bank customer demographics and transaction behavior using **Power BI**.

The project uses banking transaction data to understand customer characteristics, transaction patterns, spending behavior, and customer profitability. Interactive dashboards and visualizations help identify customer segments, analyze revenue contributions, and generate meaningful business insights.

The project demonstrates an end-to-end data analysis workflow:

**Data Import → Data Cleaning → Data Preprocessing → Feature Engineering → Exploratory Data Analysis → Customer Demographics Analysis → Transaction Behavior Analysis → Customer Segmentation → Customer Profitability Analysis → Dashboard Development**

---

## 🎯 Objectives

- Analyze customer demographics such as age, gender, and location.
- Study transaction patterns, frequency, and transaction amounts.
- Segment customers based on their transaction behavior.
- Perform RFM (Recency, Frequency, Monetary Value) analysis.
- Analyze customer revenue and account balances.
- Identify customer segments contributing the highest revenue.
- Understand spending patterns across different age groups and locations.
- Create interactive Power BI dashboards for business insights.
- Evaluate customer profitability across different segments.

---

## 🗄️ Dataset Overview

The dataset contains information about bank customers and their financial transactions.

It includes **1,048,567 transaction records** with customer demographics, account information, and transaction details.

### Key Features

- `Transaction_ID`
- `Customer_ID`
- `Customer_DOB`
- `Cust_Gender`
- `Cust_Location`
- `Cust_Account_Balance`
- `Transaction_Date`
- `Transaction_Time`
- `Transaction_Amount`

## 📊 Dashboard Analysis

### 1. Customer Demographics Analysis

This dashboard analyzes customer distribution based on demographic characteristics.

Key insights:

- The dashboard displays approximately 882K customers.
- The average customer age is 40.28 years.
- Male customers account for approximately 673K, while female customers account for approximately 268K.
- Customers are distributed across approximately 9K locations.
- The 26–35 age group has the highest number of customers.
- Major customer locations include Mumbai, New Delhi, Bangalore, Gurgaon, Delhi, and Noida.
- Interactive slicers allow filtering by age group, gender, and location.

### 2. Transaction Behavior Analysis

This dashboard examines transaction amounts, account balances, and transaction activity.

Key insights:

- Total transaction volume is approximately ₹1.64 billion.
- The average transaction amount is approximately ₹1.57K.
- The highest individual transaction value is approximately ₹1.56 million.
- The average customer account balance is approximately ₹114.90K.
- Transaction volumes vary across different days.
- Hourly transaction analysis helps identify periods of higher customer activity.

### 3. Customer Segmentation Analysis

This dashboard classifies customers based on their transaction behavior and spending patterns.

Key insights:

- Total customer revenue is approximately ₹1.64 billion.
- Customers make an average of 1.19 transactions per customer.
- Customers are classified into three segments: Occasional, Regular, and Loyal.
- Occasional customers form the largest customer segment.
- Occasional customers contribute the highest total revenue, followed by Regular and Loyal customers.
- The 26–35 age group has the highest transaction frequency.
- RFM analysis helps examine the relationship between transaction frequency and monetary value.

### 4. Customer Profitability Analysis

This dashboard evaluates revenue contribution and monetary value across customer segments.

Key insights:

- Total customer revenue is approximately ₹1.64 billion.
- The average customer monetary value is approximately ₹2.12K.
- Occasional customers generate the highest total revenue.
- Loyal customers have the highest average monetary value compared with Regular and Occasional customers.
- The 26–35 age group contributes the highest revenue.
- Customer revenue varies across locations, including Mumbai, New Delhi, Bangalore, Gurgaon, Delhi, and Kolkata.

## 📈 Key Business Insights

- The 26–35 age group represents a major customer segment in terms of customer count, transaction frequency, and revenue contribution.
- Customer transaction activity varies by day and hour.
- Occasional customers contribute the highest overall revenue among the identified customer segments.
- Loyal customers have a higher average monetary value, indicating greater value per customer.
- Customer demographics and geographical distribution help identify important customer groups and markets.
- RFM analysis provides a structured way to understand customer transaction behavior and spending patterns.

The Bank Customer Segmentation project provides insights into customer demographics, transaction behavior, revenue contribution, and spending patterns using Power BI.
